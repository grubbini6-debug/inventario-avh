# Formularios durante la sincronización

El temporizador de 20 segundos y los dos canales de tiempo real llamaban a `loadAll`. Sus extensiones volvían a crear la pantalla administrativa, las fichas de compras y otras vistas completas; se perdían valores, foco y archivos seleccionados. Además se volvía a dibujar el último módulo de Gestión aunque el usuario ya hubiera cambiado de página.

La carga de datos sigue funcionando. Antes de reemplazar una vista se comprueba si hay un modal abierto, un control enfocado o controles modificados que todavía pertenecen a esa vista. Se conservan los nodos originales: no se copian contraseñas, documentos ni borradores a almacenamiento adicional. La comprobación ocurre después de las consultas, por lo que también cubre ediciones iniciadas mientras el servidor responde. Los módulos de Gestión se actualizan visualmente solamente cuando están abiertos.

Los formularios y filtros protegidos conservan su pantalla hasta que el usuario guarda o vuelve a abrir la vista. Las acciones explícitas de guardar/navegar conservan su funcionamiento y consultan los datos ya sincronizados. Las listas de inventario y movimientos se actualizan sin reemplazar sus controles. Esto protege contra las actualizaciones internas, no persiste borradores al cerrar la pestaña o recargar la página desde el navegador.

`npm run test:browser:refresh` utiliza Chromium y respuestas de prueba para todas las URLs de Supabase; no crea usuarios, movimientos ni compras en producción. Reproduce el temporizador real con el reloj virtual, los eventos de ambos WebSockets y el botón de actualización. Verifica formularios administrativos sin guardar y después de perder el foco, una edición iniciada con una consulta en curso, foco de un campo vacío, gestión de compras, filtros, un archivo adjunto conservando el nodo original, recepción desde un celular y actualización del stock sin desviar la navegación. En la versión anterior falla porque el usuario escrito se convierte en una cadena vacía tras 20 segundos. La prueba también se ejecuta en CI.
